Overview

Sky Predict is a Ritual testnet prediction-market platform for crypto and football markets. Users bet with SkyUSD, a testnet ERC-20 token. Markets are deployed by a factory contract, resolved by the backend scheduler, and displayed through a Next.js frontend.

Contracts

SkyUSD, MarketFactory, PredictionMarket, and oracle helpers.

Frontend

Next.js app with markets, portfolio, faucet, leaderboard, and hidden admin page.

Scheduler

`scripts/auto-market.ts` creates and resolves markets in production.

RITUAL_RPC_URL=https://rpc.ritualfoundation.org
FACTORY_ADDRESS=0xYourFactory
NEXT_PUBLIC_FACTORY_ADDRESS=0xYourFactory

SKYUSD_ADDRESS=0xYourSkyUSD

Never commit private keys, API keys, `.env`, `.env.local`, logs, or runtime caches.

Quick Start

  1. Install root dependencies.
  2. Install frontend dependencies.
  3. Configure `.env`, `contracts/.env`, and `frontend/.env.local`.
  4. Compile and deploy contracts.
  5. Copy fresh addresses into all env files.
  6. Run the frontend.
  7. Start the scheduler with PM2.

Auto-Market Scheduler

The canonical production scheduler is `scripts/auto-market.ts`.

Local Run

npm run auto-market

Production with PM2

pm2 start ecosystem.config.js
pm2 logs sky-market-scheduler

Restart After Env Changes

pm2 restart ecosystem.config.js --update-env
  • Crypto markets are created daily for supported tickers.
  • Crypto betting closes 3 hours before settlement.
  • Sports fixtures are discovered from football-data.org.
  • Finished sports fixtures are resolved from full-time scores.

Admin Treasury

The hidden admin page is available at:

/admin
  • It is not linked from the landing page.
  • It requires wallet connection.
  • Only the configured owner/deployer wallet can withdraw faucet fees.
  • It reads treasury balance from `faucetFeeBalance()`.
  • It withdraws with `withdrawFees()`.

Fee Model

ActionFee
Faucet claim0.001 native Ritual token.
Place betNo protocol fee, gas only.
Claim winning payout10% protocol fee from payout.
Losing betNo claimable payout.

Troubleshooting

Approval or Bet Fails

  • Confirm token and factory addresses point to the latest reset deployment.
  • Confirm the market belongs to the current factory.
  • Confirm the user has enough SkyUSD.
  • Confirm approval targets the current market contract.
  • Confirm the betting deadline has not passed.

Faucet Claim Fails

  • Wallet must have enough native Ritual token for gas and claim value.
  • Recipient must be below the 2-claims-per-24-hours limit.
  • Frontend ABI must mark faucet as payable.
  • Frontend must use the current SkyUSD address.

PM2 Uses Old Addresses

pm2 restart ecosystem.config.js --update-env
pm2 logs sky-market-scheduler

ENOSPC

`ENOSPC` means the server has no disk space available. Free disk, clear unused caches, or remove old build artifacts.

Deployment Checklist

  • Root `.env` has current deployer and deployed addresses.
  • `contracts/.env` matches the deployed stack.
  • `frontend/.env.local` matches the same factory and SkyUSD token.
  • Contracts compile.
  • Frontend builds.
  • PM2 scheduler starts.
  • Scheduler creates markets from the current factory.
  • Faucet claim confirms and updates SkyUSD balance.
  • Approval and bet placement work on active markets.
  • Claim works after market resolution.
  • `/admin` withdraw remains owner-only.
